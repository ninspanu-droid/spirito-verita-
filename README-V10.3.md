# SPIRITO & VERITÀ V10.3

Versione applicativa: **1.0.39**.

La V10.3 migliora la tracciabilità della build Android EAS: log conservati, riepilogo anche in caso di errore e tentativo di estrazione del collegamento alla build.

**Non è un APK già compilato.** Per avviare la build servono repository GitHub, lockfile validato, Project ID EAS e secret `EXPO_TOKEN`. Il collaudo SQLCipher su dispositivo resta da eseguire.

Dettagli: `docs/V10-3-TRACCIABILITA-BUILD-ANDROID.md`.

# SPIRITO & VERITÀ — V9.3

Versione applicativa: **1.0.29**.

La V9.3 aggiunge `npm run check:crypto-runtime`, un preflight che controlla gli export delle librerie crittografiche realmente caricabili, la configurazione Expo SQLCipher e la presenza del lockfile.

**Stato verifiche:** suite Node eseguibile; installazione delle dipendenze non completata in questo ambiente; Noble non verificato runtime; nessuna build nativa o prova su dispositivo eseguita. Consultare `docs/V9-3-PREFLIGHT-CRITTOGRAFIA-EXPO.md`.
